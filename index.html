About me

Code with a clear purpose.

I build, test, and publish personal software projects — from browser extensions and small web tools to Minecraft plugins and Raspberry Pi prototypes.

On GitHub, these become useful tools such as CR-Toolkit and TTVNotifyMe, as well as experiments like the Game Radio Station. Every project is a chance to make an idea tangible and learn something new along the way.

My focus is JavaScript, Node.js, Python, and Java — always with an eye for clear interfaces, working systems, and solutions that help in everyday use.
